Cómo leer el gráfico

¿Qué significa el promedio orientativo?

Es un resumen visual del perfil de {{ data?.fruitName || 'la fruta' }}. Sirve para comparar rápidamente su comportamiento con el de las demás frutas disponibles.

¿Qué puedes interpretar?

Un valor alto indica que la fruta se encuentra relativamente por encima de otras en ese conjunto de datos. No representa un porcentaje de dulzor ni una aceptación real del consumidor.

Aroma, intensidad y aceptación son estimaciones educativas construidas a partir de las mediciones disponibles; no sustituyen una prueba sensorial con consumidores.
